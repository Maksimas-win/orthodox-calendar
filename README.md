# Православный календарь — Храм Рождества Христова (Букишкес)

Статический сайт: церковные праздники, посты, дни памяти святых, отсчёт до Пасхи
и расписание богослужений. Работает на любой год: Пасха и переходящие праздники
вычисляются автоматически, ничего не нужно обновлять в начале года.

Сборка, сервер и база данных не нужны: достаточно загрузить файлы на хостинг.

## Структура

```
index.html               — разметка страницы (расписание богослужений правится здесь)
favicon.svg              — иконка сайта
.htaccess                — настройки для Hostinger (на GitHub Pages не используется)
css/style.css            — оформление
js/data.js               — ДАННЫЕ: праздники, святые, посты (правится чаще всего)
js/church-calendar.js    — расчёты: Пасха, переходящие праздники, посты
js/app.js                — отрисовка страницы и интерактив
```

## Как править данные

Все праздники и посты хранятся в `js/data.js`, год указывать не нужно.

```js
// неподвижный праздник — дата по новому стилю 'ММ-ДД'
{ date: '12-19', type: 'revered', name: 'Святитель Николай Чудотворец', desc: '...' },

// переходящий — сколько дней до (−) или после (+) Пасхи
{ offset: 39, type: 'twelve', name: 'Вознесение Господне', desc: '...' },
```

Виды (`type`): `pascha`, `twelve`, `great`, `revered`, `local`, `icon`, `saint`, `memorial`.
Подробности — в комментарии в начале `js/data.js`.

Время богослужений меняется в `index.html`, в блоке «Расписание богослужений».

После правки `css/style.css` или файлов в `js/` увеличьте номер `?v=2` → `?v=3`
во всех четырёх ссылках в `<head>` файла `index.html`, иначе у части посетителей
до недели будет открываться старая версия из кэша.

## Как посмотреть локально

Откройте `index.html` двойным щелчком — страница работает и без сервера.

## Размещение на Hostinger

1. hPanel → **Websites** → **Manage** → **File Manager** → папка `public_html`.
2. **Удалите `default.php`** — это заглушка Hostinger («Viskas paruošta!»).
   (Файл `.htaccess` и так заставляет сервер открывать `index.html` первым, но заглушку лучше убрать.)
3. Загрузите в `public_html`: `index.html`, `favicon.svg`, `.htaccess`, папки `css` и `js`.
   Файлы `README.md` и `.gitignore` загружать не нужно.
4. Проверьте, что в hPanel включён SSL (раздел **Security → SSL**).

Если сайт лежит на GitHub, можно выгружать его прямо оттуда:
hPanel → **Advanced → Git** → указать адрес репозитория и ветку `main`, поле каталога
оставить пустым (тогда файлы попадут в `public_html`; перед первой выгрузкой папка должна быть пустой).
После каждого изменения на GitHub нажмите там же **Deploy** или включите автодеплой по webhook.

## Размещение на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него все файлы из этой папки
   (через **Add file → Upload files** или `git push`).
2. **Settings → Pages** → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<имя>.github.io/<репозиторий>/`.
