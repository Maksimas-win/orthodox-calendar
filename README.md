# Православный календарь — Храм Рождества Христова

Динамический православный календарь, который автоматически показывает информацию на текущий день.

## 🚀 Как это работает

1. **index.html** — главная страница с JavaScript
2. **calendar-data.json** — база данных календаря в формате JSON

JavaScript автоматически определяет текущую дату и загружает соответствующие данные из JSON-файла.

## 📁 Структура файлов

```
orthodox-calendar/
├── index.html          # Главная страница
├── calendar-data.json  # Данные календаря
└── README.md           # Эта инструкция
```

## 🔧 Настройка GitHub + Hostinger

### Шаг 1: Создать репозиторий на GitHub

1. Зайди на [github.com](https://github.com) и создай аккаунт (если нет)
2. Нажми **New repository**
3. Название: `orthodox-calendar`
4. Выбери **Public**
5. Нажми **Create repository**

### Шаг 2: Загрузить файлы

1. В новом репозитории нажми **uploading an existing file**
2. Перетащи файлы `index.html` и `calendar-data.json`
3. Нажми **Commit changes**

### Шаг 3: Подключить к Hostinger

1. Зайди в **hPanel** → **Websites** → **bukhram.info**
2. Найди раздел **Git** или **GitHub integration**
3. Подключи репозиторий `orthodox-calendar`
4. Hostinger будет автоматически обновлять сайт при изменениях в GitHub
